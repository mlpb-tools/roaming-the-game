### 🎯 15 Activités Interactives

#### Module 1 (450 XP total)
1. **Quiz des Mythes** - 10 questions vrai/faux avec feedback
2. **Mur des Freins** - Glisser-déposer pour associer freins/solutions
3. **Le Profiler** - Grille ROAMING pour diagnostiquer un profil

#### Module 2 (580 XP total)
4. **Encyclopédie Dispositifs** - Recherche de programmes adaptés
5. **Plan de Route** - Timeline interactive avec étapes à organiser
6. **Boîte SOS** - Escape game pour gérer situations d'urgence
7. **Atelier Famille** - QCM pour répondre aux parents

#### Module 3 (300 XP total)
8. **Messagerie Virtuelle** - Simulation chat avec jeune en mobilité
9. **Détecteur d'Alerte** - Analyse de cas pour identifier signaux

#### Module 4 (420 XP total)
10. **Entretien Miroir** - Choix de questions par phase
11. **CV Augmenté** - Traduction expérience en compétences
12. **Storytelling** - Construction d'un pitch inspirant

#### Module 5 (400 XP total)
13. **Jeu des Rôles** - Mapping de l'écosystème mobilité
14. **Réseau Cartographique** - Base de données partenaires
15. **Lab' Capitalisation** - Génération de fiche REX

## 🚀 Déploiement

### Option 1 : Utilisation Locale
1. Décompresser `roaming-app.zip`
2. Ouvrir `index.html` dans un navigateur
3. Commencer la formation

### Option 2 : Hébergement Web
1. Uploader tous les fichiers sur un serveur web
2. Accès via URL (ex: `https://mission-locale.fr/roaming`)
3. Aucune configuration serveur requise (site statique)

### Option 3 : Intranet
1. Placer sur un serveur intranet
2. Partager le lien aux conseillers
3. Chaque utilisateur a sa propre progression
