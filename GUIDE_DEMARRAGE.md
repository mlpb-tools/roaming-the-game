# 🚀 GUIDE DE DÉMARRAGE RAPIDE - ROAMING APP

## ⚡ Installation en 3 étapes

### 1️⃣ Télécharger
- Téléchargez le fichier `roaming-app.zip`
- Décompressez-le sur votre ordinateur

### 2️⃣ Ouvrir
- Double-cliquez sur le fichier `index.html`
- L'application s'ouvre dans votre navigateur web

### 3️⃣ Commencer
- Cliquez sur "Commencer" du Module 1
- Suivez les activités interactives
- Votre progression est sauvegardée automatiquement !

---

## 🎮 Comment utiliser l'application

### Dashboard Principal
Le tableau de bord affiche :
- 📊 **Vos statistiques** : XP, badges, modules complétés
- 🗺️ **Carte du parcours** : Visualisation des 5 modules
- 🏆 **Collection de badges** : Vos récompenses

### Navigation dans les modules
1. **Cliquez sur un module** pour y accéder
2. **Complétez les séquences** dans l'ordre
3. **Gagnez des XP** à chaque activité terminée
4. **Déverrouillez** le module suivant

### Types d'activités
- 🎯 **Quiz interactifs** : Questions vraies/fausses
- 🎮 **Glisser-déposer** : Associer éléments
- ✍️ **Formulaires** : Remplir des grilles d'analyse
- 💬 **Simulations** : Conversations avec des jeunes
- 📊 **Études de cas** : Analyser des situations réelles

---

## 💡 Astuces & Conseils

### ✅ Pour une meilleure expérience
- Utilisez un navigateur moderne (Chrome, Firefox, Edge)
- Activez JavaScript
- Autorisez les cookies pour sauvegarder votre progression
- Prévoyez 15-20h pour compléter tout le parcours

### ⚠️ À éviter
- ❌ Ne videz pas le cache du navigateur
- ❌ N'utilisez pas le mode navigation privée
- ❌ Ne fermez pas la fenêtre pendant une activité

### 🔄 Réinitialiser votre progression
Si vous souhaitez recommencer à zéro :
1. Ouvrez la console du navigateur (F12)
2. Tapez : `localStorage.clear()`
3. Rafraîchissez la page

## 🆘 Problèmes Fréquents

### L'application ne s'affiche pas correctement
✅ **Solution** : Vérifiez que tous les fichiers CSS sont bien chargés (dossier `styles/`)

### Ma progression a disparu
✅ **Solution** : Vérifiez que vous n'avez pas changé de navigateur ou vidé le cache

### Les activités ne répondent pas
✅ **Solution** : Rafraîchissez la page (F5) et recommencez l'activité

### Je ne peux pas accéder au module suivant
✅ **Solution** : Assurez-vous d'avoir complété TOUTES les séquences du module précédent
